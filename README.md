## ✨ Features

- 🌳 **Interactive Curriculum Tree**: Complete prerequisite and dependency graph for the Technion Faculty of Mechanical Engineering curriculum.
- 📊 **GPA & Credit Analytics**: Real-time grade distribution, radar charts, degree milestones, and target grade simulator.
- 📋 **Notion-Style Task Center**: Side-peek task editor, priority flags, course tags, and due dates.
- 📅 **Interactive Calendar**: Semester overview, exam dates, day details modal, and Technion Moodle cloud sync.
- 🔄 **Cloud & Offline Sync**: Supabase real-time multi-device sync + full offline PWA service worker cache.

## 🖥️ Desktop Installation (Windows)
Semestero ME can also be run as a standalone Windows desktop app:
1. Clone the repository:
   ```bash
   git clone https://github.com/adir2368/Semestero-ME.git
   cd Semestero-ME
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the app:
   ```bash
   npm start
   ```
4. Package for Windows:
   ```bash
   npm run pack
   ```
