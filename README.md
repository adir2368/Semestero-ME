## ❓ שאלות נפוצות והסברים אקדמיים (Academic FAQ)

### איך מחושב הממוצע ב-Semestero ME?
הממוצע באפליקציה מחושב כממוצע משוקלל מדויק לפי נקודות זכות (נ״ז):
$$\text{ממוצע} = \frac{\sum (\text{ציון בקורס} \times \text{נקודות זכות בקורס})}{\sum \text{נקודות זכות בקורסים עם ציון}}$$
- **קורסים בינאריים ופטורים**: קורסים בעלי ציון "עבר" ופטורים (כגון פטור מילואים 2 נק״ז) מזכים בנקודות לתואר אך אינם נכללים בממוצע.
- **סימולטור What-If**: מאפשר הזנת ציוני תחזית לקורסים שטרם הסתיימו לקבלת הממוצע המצטבר הצפוי.

### לאילו מסלולים ותארים האפליקציה מתאימה?
האפליקציה נבנתה במיוחד עבור הסטודנטים בפקולטה להנדסת מכונות בטכניון:
1. **מסלול הנדסת מכונות כללי** (157.5 נק״ז - קטלוגים תשפ״ד עד תשפ״ז).
2. **תוכנית המצטיינים ברקים** (משולב תואר ראשון ושני - 171.5 נק״ז).
3. **מגמות התמחות**: רובוטיקה ובקרה, מכניקת מוצקים, ביו-מכניקה, אנרגיה וזרימה ועוד.
4. מאגר של למעלה מ-2,055 קורסי טכניון מתוך CheeseFork המאפשר חיפוש ושיבוץ כל קורס בחירה, ספורט ומל״ג.

### האם המידע שלי מאובטח ופרטי?
כן, באופן מוחלט. סמסטרו ME בנויה בארכיטקטורת **Local-First**: כל הציונים, המטלות, ההערות וההגדרות נשמרים ישירות על גבי הדפדפן או המכשיר שלך, ללא מעקב פרסומי וללא שרתים מסחריים.

## 🖥️ התקנת אפליקציית מחשב (Windows Desktop App)
סמסטרו ME זמינה גם כאפליקציית Windows שולחנית עצמאית (Electron):
```bash

cd Semestero-ME
npm install
npm start
```

## 📱 פיתוח ובנייה למובייל (iOS & Android Native)
האפליקציה פועלת כאפליקציית מובייל היברידית מלאה באמצעות **Capacitor 8**:

### 🍎 iPhone & iOS (Xcode Workspace)
```bash
# סנכרון נכסי הווב לפרויקט iOS
npm run build:ios

# פתיחת הפרויקט ב-Xcode (במערכת macOS)
npm run open:ios
# או פתיחה ישירה של הקובץ ios/App/App.xcodeproj
```

### 🤖 Android
```bash
# סנכרון ובניית APK
npm run build:apk

# פתיחה ישירה ב-Android Studio
npm run open:android
```
